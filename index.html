Options de l'embed
🌍 Connexion au site en ligne (GitHub)
Avec une clé GitHub, « Publier sur le site » met directement à jour le site en ligne (visible par tous en 1 à 2 minutes). Sans clé, Embed Sender écrit seulement dans le fichier patchnotes.js de ton PC.
  1. Ouvre github.com/settings/personal-access-tokens/new.
  2. Token name : Embed Sender · Expiration : au choix.
  3. Repository access : Only select repositories → vicecity-site.
  4. Permissions → Contents : Read and write.
  5. Generate token, copie la clé et colle-la ici, puis Tester.
🔒 La clé reste dans ce navigateur (comme tes webhooks), n'est pas incluse dans la sauvegarde et ne peut modifier que le dépôt du site. Ne la partage jamais.

🌍Mettre le site en ligne

Pour l'utiliser depuis ton téléphone, n'importe où, ou le partager avec ton équipe, tu peux l'héberger gratuitement :
  1. Renomme le fichier webhook-embed.html en index.html et place-le seul dans un dossier.
  2. Va sur app.netlify.com/drop (ou GitHub Pages) et glisse ce dossier dans la page.
  3. Tu obtiens une adresse https://… à ouvrir partout. Crée un compte gratuit pour la garder.
🔒 Les webhooks restent enregistrés dans le navigateur de chaque personne, jamais sur le site lui-même. Les liens « 🔗 Partager » fonctionnent pleinement une fois le site en ligne.

📘Aide-mémoire markdown

👋 Bienvenue sur Embed Sender

Crée de beaux messages Discord et envoie-les avec un webhook, en 4 étapes :
  1. Crée un webhook dans Discord : Paramètres du salon → Intégrations → Webhooks → Nouveau webhook → « Copier l'URL du webhook ».
  2. Colle l'URL dans la carte 🔗 Webhook, puis clique sur « Vérifier » et « Enregistrer ».
  3. Compose ton message : texte, embeds, sondage, fichiers… L'aperçu se met à jour en direct.
  4. Envoie avec 🚀, ou programme l'envoi avec ⏰.
