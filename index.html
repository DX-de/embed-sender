🔗Webhook obligatoire

L'adresse secrète d'un salon Discord : c'est elle qui permet d'y envoyer des messages.
❓ Comment obtenir l'adresse d'un webhook ?
  1. Sur Discord, survole le salon voulu et clique sur ⚙️ Modifier le salon.
  2. Va dans Intégrations → Webhooks → Nouveau webhook.
  3. Donne-lui un nom (ex : Annonces) et une image si tu veux.
  4. Clique sur Copier l'URL du webhook, colle-la ci-dessus, puis Vérifier et Enregistrer.
🔒 Garde cette adresse secrète : n'importe qui l'ayant pourrait écrire dans ton salon. Elle reste uniquement dans ce navigateur.
Modifier le nom / l'avatar du webhook sur Discord
Change le nom et l'avatar par défaut du webhook sur Discord, pour tous les messages où tu ne mets pas de « Nom affiché ».

📋Publier un patchnote

  1. 1Écris la version, le titre et les changements ci-dessous.
  2. 2Clique sur 🧩 Créer l'embed (ou ⚡ Les deux si ton site est relié) : le message Discord se prépare tout seul.
  3. 3La page Nouveau message s'ouvre avec ton patchnote : choisis le salon, vérifie, puis 🚀 Envoyer.

✏️Ton patchnote

Écris librement, une ligne par élément. Une ligne qui commence par un emoji (🔧, ✅, ⚙️…) devient un titre sur le site. Tu peux aussi utiliser la liste « Changements » ci-dessous, ou les deux.
Options de l'embed
🌍 Relier ton site web (facultatif, GitHub)
Seulement si ton site est hébergé sur GitHub et lit ses patchnotes dans un fichier js/patchnotes.js au format Embed Sender. Avec une clé GitHub, « Publier sur le site » met directement à jour le site en ligne (1 à 2 minutes). Sans site relié, utilise simplement 🧩 Créer l'embed.
  1. Ouvre github.com/settings/personal-access-tokens/new.
  2. Token name : Embed Sender · Expiration : au choix.
  3. Repository access : Only select repositories → le dépôt de ton site.
  4. Permissions → Contents : Read and write.
  5. Generate token, copie la clé et colle-la ici, puis Tester.
🔒 La clé reste dans ce navigateur (comme tes webhooks), n'est pas incluse dans la sauvegarde et ne peut modifier que le dépôt du site. Ne la partage jamais.

👋 Bienvenue sur Embed Sender

Crée de beaux messages Discord et envoie-les avec un webhook, en 4 étapes :
  1. Crée un webhook dans Discord : Paramètres du salon → Intégrations → Webhooks → Nouveau webhook → « Copier l'URL du webhook ».
  2. Colle l'URL dans la carte 🔗 Webhook, puis clique sur « Vérifier » et « Enregistrer ».
  3. Compose ton message : texte, embeds, sondage, fichiers… L'aperçu se met à jour en direct.
  4. Envoie avec 🚀, ou programme l'envoi avec ⏰.

🧭 Le menu

Chaque chose a sa page dans le menu de gauche : Nouveau message (en 3 étapes : salon, écrire, envoyer), Patchnote, Modèles, Notes, Équipe, Historique et Paramètres. Les options rares (sondage, boutons, fichiers…) sont dans « ➕ Options supplémentaires » à l'étape 2.

📋 Patchnote

Page Patchnote : écris la version, le titre et les changements, puis 🧩 Créer l'embed. Si ton site web est relié (section « Relier ton site web »), ⚡ Les deux l'ajoute aussi au site.

👥 Équipe

Page Équipe : renseigne ton ID Discord, crée une équipe avec le webhook d'un salon privé, puis ajoute tes membres avec leur ID Discord (ils reçoivent une notification). Les notes d'équipe s'affichent dans la page Notes avec leur auteur.

📝 Bloc-notes

Onglet 📝 Notes : garde tes idées et brouillons. Enregistrement automatique, recherche, notes épinglées, et un clic pour les mettre dans le message ou en faire un embed.
